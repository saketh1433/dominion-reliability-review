# Sources and attribution

This project combines publicly available datasets and original analysis.

- **U.S. Energy Information Administration (EIA):** EIA-861 annual utility reporting and EIA-930 hourly demand. https://www.eia.gov/electricity/data/eia861/ and https://www.eia.gov/electricity/gridmonitor/
- **Catalyst Cooperative PUDL:** historical EIA-861 reliability, smart metering, and electricity-sales extracts, used under the stated **Creative Commons Attribution 4.0 (CC BY 4.0)** terms. https://docs.catalyst.coop/pudl/en/stable/data_access.html . Data is excerpted/standardized for this project; the analyses, joins and charts are project work.
- **NOAA NCEI Storm Events Database:** NOAA Storm Events details files, 2013–2025, with NWS zone-to-county lookup. https://www.ncei.noaa.gov/pub/data/swdi/stormevents/csvfiles/ and https://www.weather.gov/gis/ZoneCounty
- **Dominion Energy annual report and investor presentations:** referenced for published company context and numerical reconciliation, not copied into this repository as full documents.

For precise source files, versions and transformation details, see [docs/01_sources.md](docs/01_sources.md). No software license is declared for this repository by this attribution note; choosing a code license remains the owner's decision.
